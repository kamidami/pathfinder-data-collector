# Data flow

1. A human creates a pending collection job.
2. Future adapters will discover and fetch public official pages into ignored cache files.
3. Extracted candidate fields retain field-level evidence and expose conflicts.
4. A human reviews candidates; automation never marks them verified or approved.
5. Approved records are validated against a versioned contract and exported as CSV.
6. Pathfinder may consume that CSV through its own import process; there is no database link.
