# Privacy and collection rules

- Use official, public sources only and respect website terms and robots instructions.
- Never bypass CAPTCHA, authentication, paywalls, or other access controls.
- Do not crawl aggressively; future fetching must use conservative rates and caching.
- Never write directly to a Pathfinder database. Exchange only versioned contract files.
- Every extracted value requires evidence. Surface conflicts rather than silently choosing.
- Leave missing values blank; do not guess.
- Automatic collection status is never verification. A human must approve before export.
- Do not predict admission, visa, or scholarship probability.
- Do not collect student names, email addresses, IP addresses, browser fingerprints,
  credentials, or Pathfinder sessions.
- Do not commit large copyrighted page copies. Raw pages belong only in ignored local cache.
- Keep evidence excerpts short and limited to what is necessary for review.
- Resolve and reject private, local, link-local, reserved, or otherwise non-public destinations;
  apply the same checks to redirects.
- Treat robots unavailability conservatively. Robots permission does not replace legal or site
  terms review, particularly before bulk collection or content reuse.
- Fetch only bounded HTML/plain text with an identifiable user agent, process-local per-host
  delays, finite retries, and ignored cache storage.
